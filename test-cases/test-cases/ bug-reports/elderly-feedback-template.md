```markdown
# Template for Collecting Elderly User Feedback

Ask the senior to complete after 5 minutes of ChatGPT use (with help if needed):

1. Were you able to start a conversation without help? [Yes/No/With help]
2. What was the most confusing thing you saw? (write or circle)
3. Were the answers too long / too short / just right?
4. Would you use ChatGPT again? [Yes/No/Maybe]
5. What would make it easier for you? (e.g., bigger buttons, voice only)

**Tester notes:** Record facial expressions, hesitation, questions asked.
```
